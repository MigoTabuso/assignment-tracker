# Student Assignment Tracker (CS0053 - TN33)

## Project Purpose
A console-based C++ application designed to help students track assignments, manage due dates, and maintain records collaboratively using VS Code, Git, and GitHub.

## Core Features
1. Add Assignment
2. View All Assignments
3. Search Assignment
4. Update Assignment Status
5. Delete Assignment

## Requirements & Compilation
* **Compiler:** `g++` (C++11 or higher)
* **Compile Instruction:** `g++ main.cpp tracker.cpp -o tracker`
* **Run Instruction:** `./tracker`
